# BETWEEN THE LINES

Персональный статический сайт-подарок: маленький фильм в процессе, а не романтический лендинг.

Контент живёт в папке `content/`. Код сайта — в `index.html`, `css/` и `js/`. Чтобы изменить историю, правьте JSON, а не JavaScript.

---

## 1. Как открыть сайт локально

Сайт нужно открывать через локальный сервер. Если открыть `index.html` двойным щелчком, браузер может не загрузить JSON-файлы.

### Вариант A — Python

В папке проекта выполните:

```bash
python -m http.server 8080
```

Затем откройте в браузере: [http://127.0.0.1:8080](http://127.0.0.1:8080)

### Вариант B — Node.js

```bash
npx --yes serve -p 8080
```

Готово: это обычный статический сайт. Backend и база данных не нужны.

## 2. Где менять название

Файл: `content/config.json`

- `projectTitle` — крупный заголовок на первом экране (`BETWEEN THE LINES`)
- `filmTitle` — подзаголовок раздела «НАШ ФИЛЬМ»
- блок `titleCard` — имя, подзаголовок, короткая фраза, номер плёнки, техническая подпись

Пример:

```json
"projectTitle": "BETWEEN THE LINES",
"filmTitle": "[НАЗВАНИЕ ФИЛЬМА]",
"titleCard": {
  "name": "[ИМЯ]",
  "subtitle": "[ПОДЗАГОЛОВОК]",
  "phrase": "[КОРОТКАЯ ФРАЗА]"
}
```

Тексты кнопок и подписей (в том числе «ЕЩЁ НЕ СНЯТО») лежат в `copy`.

---

## 3. Где менять дату начала

Файл: `content/config.json`

```json
"startDate": "2026-09-29T16:20:00",
"timezone": "Europe/Moscow"
```

`startDate` — это местное время **в указанном часовом поясе**, а не время компьютера посетителя.

Эта дата используется:

- как начало истории;
- как нулевая точка счётчика.

Не меняйте формат: `ГГГГ-ММ-ДДTЧЧ:ММ:СС`.

## 4. Как добавить новую сцену

Файл: `content/timeline.json`

Добавьте объект в массив `scenes`:

```json
{
  "id": "scene-04",
  "number": 4,
  "date": "2026-10-05",
  "time": "18:00",
  "title": "[НАЗВАНИЕ СЦЕНЫ]",
  "location": "[МЕСТО]",
  "description": "[ОПИСАНИЕ]",
  "quote": "[ЦИТАТА]",
  "voiceOver": "[ЗАКАДРОВЫЙ ТЕКСТ]",
  "notes": "[ЗАМЕТКИ]",
  "image": "assets/images/timeline/scene-04.jpg",
  "imageAlt": "[ОПИСАНИЕ КАДРА]",
  "metadata": {
    "reel": "001"
  }
}
```

Что можно не писать: `quote`, `voiceOver`, `notes`, `image`, `metadata`, `number`. Сайт не сломается.

Если `number` нет, номер сцены проставится по порядку после сортировки.

После сохранения файла обновите страницу в браузере.

## 5. Как добавить изображение

1. Положите файл в нужную папку:
   - кадр дня: `assets/images/daily/`
   - сцена timeline: `assets/images/timeline/`
   - декоративное: `assets/images/decorative/`
2. В JSON укажите **относительный путь от корня сайта**, например:

```text
assets/images/timeline/scene-04.jpg
```

3. Заполните `imageAlt` — короткое описание для доступности.

Если файла нет или путь ошибочный, вместо картинки появится аккуратный кадр:

`[КАДР ПОКА НЕ ДОБАВЛЕН]`

Пока изображения нет, можно написать `"image": null`.

## 6. Как добавить ежедневный контент (кадр дня)

Файл: `content/daily.json`

- `default` показывается, если на сегодня нет отдельной записи.
- `entries` — записи на конкретные даты.

Дата должна совпадать с календарным днём в часовом поясе из `config.json` (`Europe/Moscow` по умолчанию).

```json
{
  "date": "2026-10-02",
  "type": "text",
  "kicker": "TODAY'S FRAME",
  "title": "[КАДР ДНЯ]",
  "image": "assets/images/daily/2026-10-02.jpg",
  "imageAlt": "[ОПИСАНИЕ ИЗОБРАЖЕНИЯ]",
  "text": "[ТЕКСТ КАДРА ДНЯ]",
  "extra": "[ДОПОЛНИТЕЛЬНАЯ ИНФОРМАЦИЯ]",
  "quote": "[ЦИТАТА]"
}
```

Поле `type` можно ставить таким: `text`, `image`, `quote`, `fact`, `joke`, `meme`, `question`, `quiz`. Сайт показывает те поля, которые заполнены.

## 7. Как добавить приветствие

Файл: `content/greetings.json`

```json
{
  "date": "2026-10-02",
  "greeting": "[ПРИВЕТСТВИЕ]",
  "phrase": "[КОРОТКАЯ ФРАЗА]",
  "note": "[ДОПОЛНИТЕЛЬНАЯ СТРОКА]"
}
```

Если на сегодня записи нет, берётся `default`.

Дата на экране подставляется автоматически.

## 8. Как добавить quiz

В `content/daily.json` добавьте запись с `"type": "quiz"` и блоком `quiz`:

```json
{
  "date": "2026-10-12",
  "type": "quiz",
  "title": "[КАДР ДНЯ]",
  "text": "[ТЕКСТ КАДРА ДНЯ]",
  "quiz": {
    "question": "[ВОПРОС]",
    "options": [
      { "id": "a", "text": "[ВАРИАНТ А]", "correct": false },
      { "id": "b", "text": "[ВАРИАНТ Б]", "correct": true }
    ],
    "reveal": "[ПОЯСНЕНИЕ]"
  }
}
```

`correct: true` отметьте у одного варианта. После ответа появится `reveal`.

В файле уже есть учебный пример на дату `2099-01-01` — он не показывается «сегодня», это только образец структуры.

## 9. Как добавить музыку

1. Положите файл, например: `assets/audio/score.mp3`
2. В `content/config.json` укажите:

```json
"audio": {
  "src": "assets/audio/score.mp3",
  "loop": true,
  "volume": 0.32
}
```

Музыка **не начинается сама**. На странице есть кнопка `SOUND ON / SOUND OFF`. Выбор `on`/`off` запоминается в браузере, но звук всё равно включается только по нажатию — браузеры так и должны работать.

Пока файла нет, кнопка показывает `SOUND — NO REEL` и не ломает сайт.

## 10. Как изменить настройки анимаций

В `content/config.json` блок `effects`:

| Поле | Что делает |
| --- | --- |
| `grain` | зерно плёнки |
| `flicker` | мерцание |
| `scratches` | царапины |
| `jitter` | лёгкое дрожание кадра |
| `ripple` | запас под искажение (очень слабое) |
| `dust` | пылинки |
| `speed` | общая скорость анимаций (`1` — нормально, `0.5` — медленнее) |

Блок `features` включает и выключает крупные части:

- `filmEffects` — слой зерна и мерцания
- `sideReels` — боковая киноплёнка
- `audio` — кнопка звука
- `unshotScene` — кадр «ЕЩЁ НЕ СНЯТО»
- `introFade` — затемнение FADE IN
- `scrollReveal` — появление секций при прокрутке

На телефонах эффекты сами становятся слабее. Если у человека включено «уменьшить движение» в системе, анимации отключаются.

## 11. Как работает timeline

1. Сайт читает `content/timeline.json`.
2. Сцены сортируются по `date` + `time` в часовом поясе проекта.
3. Если задано поле `timestamp`, оно имеет приоритет.
4. После всех снятых сцен автоматически добавляется кадр **ЕЩЁ НЕ СНЯТО**. Это не событие из JSON и не дата будущей встречи.

Начало истории по замыслу: **29 сентября 2026, 16:20, Europe/Moscow**. Первую сцену лучше ставить именно на этот момент.

---

## 12. Как работает счётчик

Счётчик внизу страницы считает время от `startDate` в `timezone`.

- Если начало уже наступило: заголовок **НАШ ФИЛЬМ ИДЁТ УЖЕ**, идут дни / часы / минуты / секунды.
- Если начало ещё в будущем: заголовок **ДО ПЕРВОГО КАДРА**, показывается оставшееся время. Отрицательных чисел не будет.

Часовой пояс берётся из конфигурации, а не с устройства гостя. Человек в другой стране увидит тот же фильм по московскому времени.

## 13. Как опубликовать сайт

Это набор статических файлов. Корень сайта — папка, где лежит `index.html`.

### GitHub Pages

1. Создайте репозиторий и загрузите все файлы проекта.
2. Settings → Pages → Source: **Deploy from a branch**.
3. Branch: `main`, folder: `/ (root)`.
4. Если сайт будет по адресу `https://username.github.io/BetweenTheLines/`, пути уже относительные и должны работать.

В корне лежит файл `.nojekyll`, чтобы GitHub не обрабатывал сайт как Jekyll-блог.

### Cloudflare Pages

1. Войдите в Cloudflare Pages и подключите репозиторий.
2. Build command оставьте пустым.
3. Output directory: `/` (корень).
4. Publish.

### Netlify

1. Add new site → Import from Git (или перетащите папку в Netlify Drop).
2. Build command: пусто.
3. Publish directory: `.` (корень проекта).

После публикации проверьте, что открываются `content/config.json` и картинки. Если видите пустые заглушки вместо сцен — скорее всего сайт открыт не из корня проекта.

## Структура папок

```text
/
  index.html
  css/styles.css
  js/app.js
  content/
    config.json
    greetings.json
    daily.json
    timeline.json
  assets/
    images/daily/
    images/timeline/
    images/decorative/
    audio/
    video/
```

Правило: **тексты и даты — в JSON, картинки и звук — в assets, логика — в js**.

## Если что-то не видно

- Обновите страницу с очисткой кэша.
- Убедитесь, что сервер запущен из папки проекта.
- Проверьте запятые в JSON (лишняя запятая в конце часто ломает файл). Можно проверить файл на [jsonlint.com](https://jsonlint.com).
- Если JSON отсутствует, сайт всё равно откроется с внутренними заглушками.
